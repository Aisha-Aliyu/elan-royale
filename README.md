# Elan Royale

A restaurant website with online table booking, built with Next.js, TypeScript, Prisma and PostgreSQL. Guests can browse the menu by category and book a table, and each booking is validated and saved to the database.

Live demo: https://elan-royale.vercel.app

## Features

- A landing page with a cinematic hero section and subtle animation.
- Table booking with form validation, saved to PostgreSQL through Prisma.
- A menu you can browse by category.
- Responsive from small phones up to wide screens.
- Pages rendered on the server or at build time with the Next.js App Router.
- TypeScript throughout, with types generated by Prisma.
- A custom Tailwind theme for the colours and animations.

## Run it locally

You'll need Node.js 18 or newer and a PostgreSQL database. A local one works, or a free hosted one from Supabase or Neon.

```bash
git clone https://github.com/Aisha-Aliyu/elan-royale.git
cd elan-royale
npm install
```

Create a `.env` file in the project root:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/elan_royale"
```

Set up the database and start the app:

```bash
npx prisma migrate dev --name init
npx prisma generate
npm run dev
```

Then open http://localhost:3000.

## Deployment

It's deployed on Vercel with a hosted PostgreSQL database. Set `DATABASE_URL` in the Vercel project's environment variables.
